## 📖 About

🔹 **Terraria — The Clicker Class** is a powerful tool built to help you play Terraria with a unique clicker-game inspired class featuring click-based combat and special abilities. The Clicker Class adds clicking mechanics to Terraria's class system, complete with unique weapons, armor, and upgrades.

🔸 Whether you're a seasoned professional or just getting started, **Terraria — The Clicker Class** delivers a clean, intuitive experience packed with everything you need — right out of the box.
